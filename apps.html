ארגז הכלים לפעיל החברתי

פרויקט של רם אגמוןהמידע באתר עלול להיות שגויהירוקים הוד השרון
← חזרה למפת ה-API
הדף נפתח כקובץ מקומי (file://) ולכן אינו יכול לטעון את הנתונים.

הדפדפן חוסם מודולי ES ממקור null — זו הגבלת אבטחה של הדפדפן, לא תקלה באתר. הפעל שרת מקומי מתיקיית הפרויקט: 

python3 -m http.server 8000

ולאחר מכן פתח http://localhost:8000/apps.html.

לחלופין, ללא שרת כלל — dist/apps.html הוא קובץ יחיד ועצמאי שעובד בפתיחה ישירה מהדיסק.

על העמוד הזה

כל האפליקציות שבנויות על גבי נתונים ממשלתיים באתר הזה, מקובצות לפי מה שרלוונטי למי שמגיע - לא לפי מקור הנתונים הטכני. מפת ה-API המלאה, עם כל הפורטלים והממשקים, נמצאת ב🏠עמוד הבית.

משוב ותגובות

רעיון לאפליקציה, באג שמצאתם, או סתם משהו שרציתם להגיד? כתבו כאן - אפשר גם להשאיר תגובות אנונימיות.
לתגובות אנונימיות כתבו אנונימי בשם.

הטמעה באתר אחר

רוצים את רשימת האפליקציות הזו - כולל עתידיות - באתר משלכם, למשל בלוק "Custom HTML" ב-WordPress? dist/wordpress-embed.html היא גרסה עצמאית של הרשת שלמעלה בדיוק לכך, שנראית זהה ומתעדכנת אוטומטית בכל שינוי בapis.json. שתי דרכים להטמיע - שתיהן תמיד מציגות את הגרסה החיה, בלי צורך להדביק מחדש כשמתווספת אפליקציה:

HTML (iframe) - הכי פשוט, שורה אחת:

<iframe src="https://agmonr.github.io/govapiportal/dist/wordpress-embed.html" loading="lazy" style="width:100%;border:0;min-height:900px" title="כל האפליקציות"></iframe>

JavaScript - טוען את התוכן ישירות לתוך העמוד שלכם (בלי מסגרת/גלילה נפרדת של iframe), למי שהתבנית לא מאפשרת iframe: 

<div id="ram-govapps-embed-target"></div>
<script>
fetch('https://agmonr.github.io/govapiportal/dist/wordpress-embed.html')
  .then(function (r) { return r.text(); })
  .then(function (html) { document.getElementById('ram-govapps-embed-target').innerHTML = html; });
</script>
